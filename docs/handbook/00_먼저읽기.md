## 폴더 안내

| 경로 | 내용 |
| --- | --- |
| `source/` | v12 커밋의 전체 추적 소스. 의존성 잠금 파일, 테스트, 글꼴과 라이선스 포함 |
| `handbook/` | 이번에 작성한 한국어 인계 문서 |
| `reference/CHR_Web_Harness_r6/` | 실제 참조한 하네스 문서 원문 일부. 전체 하네스 실행 패키지는 아님 |
| `deployment/current_v12.tar.gz` | v12 저장·배포에 사용한 빌드 산출물. 소스 수정의 기준은 아님 |
| `metadata/` | 버전 정보, 커밋 이력, 파일별 SHA-256, 패키지 검증 결과 |

`source/`의 코드는 해당 커밋 그대로 보존했습니다. `handbook/`은 현재 동작을 설명하는 인계 문서입니다. 소스 README에 단계별 과거 설명이 남아 있을 수 있으므로, v12 화면 설명은 이 인계 문서와 실제 실행 코드를 함께 확인하세요.
