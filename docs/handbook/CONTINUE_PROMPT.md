# 다음 작업자 시작 지시문

융합본부 LoL 내전 사이트 v12를 이어서 작업한다. 먼저 `00_먼저읽기.md`와 `handbook/`을 읽고 `source/`의 실제 코드와 비교한다. 이 ZIP에 운영 DB 데이터와 비밀 설정이 포함되어 있다고 가정하지 않는다.

현재 운영 사이트는 https://jininfra-lol-inhouse.haeram0419.chatgpt.site 이며 프로젝트 ID는 `appgprj_6ac6048bd07c8191a04c2a9984ad7c59`, 패키지 기준 커밋은 `aca78cc8665f7a5be2aef674887fac9233187f5c`다. 계속 운영 사이트를 수정한다면 현재 원격 상태를 먼저 확인하여 더 최근 변경을 덮어쓰지 않는다.

사용자의 최신 디자인 피드백은 “하네스를 참고했는가, 전혀 인터랙티브하지 않고 심심하다”였다. v12에서 CHR Web Harness r6 문서를 실제로 참고하고 개인 성적을 공통 라인/챔피언 필터, 직접 조작 가능한 타임라인, 클릭 가능한 경기 하이라이트, 3개 보기로 개편했다. 이후 사용자의 디자인 만족 확인은 아직 없다. 정적인 장식이나 테스트 건수로 경험 품질이 증명되었다고 말하지 않는다.

다음 변경은 현재 사용자 요청에 맞춰 범위를 정한다. 명시적인 새 지시가 없다면 먼저 실제 브라우저/모바일의 첫 화면, 직접 드래그, 필터 변경 시 정보 연결, 작은 글자·겹침·가로 넘침을 확인하는 것이 우선이다. 지원되는 브라우저 도구가 없는 경우 수행했다고 보고하지 않는다.

반드시 유지할 조건:

- 경기 기록이 유일한 통계 원천이다. null을 0으로 바꾸지 않는다.
- 내부 playerId를 유지하고 현재·별칭·경기 당시 닉네임을 분리한다.
- 관리자만 등록/수정/삭제 가능하고, 뷰어는 조회만 한다.
- 해람 24경기 데모는 실제 기록과 분리한다.
- 회사 이미지 로고를 다시 넣지 않는다. Paperlogy와 기존 색상 언어를 존중한다.
- Score/MMR/MVP/ACE 값을 임의 생성하지 않는다. 이번 통계 탐색을 셔플 점수에 자동 반영하지 않는다.
- 도메인 규칙은 `domain/`에서 고치고 브라우저 복사본을 동기화한다.
- 관련 테스트와 빌드, 검증 범위 및 미검증 항목을 함께 보고한다.

완료 보고에는 무엇이 달라졌는지, 왜 바꿨는지, 실제로 검증한 범위와 한계, 게시했다면 정확한 URL을 포함한다.
