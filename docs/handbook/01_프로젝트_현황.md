# 01. 프로젝트 현황

## 목적과 현재 상태

현재는 **v12 게시 완료** 상태입니다. 최신 변경은 개인 성적의 연동 탐색 구조입니다. 운영 Site의 접근 범위는 public이며, 앱의 편집 권한은 관리자에게만 부여됩니다. 공개 열람과 편집 권한은 서로 다른 계층입니다.

## 페이지 구성

| 경로 | 용도 |
| --- | --- |
| `index.html` | 매치 센터, 참가자·닉네임 관리, 셔플, 현재 시리즈 |
| `history.html` | 날짜별 대전 기록과 세트 상세, 관리자 기록 편집 |
| `players.html` | 선수 목록과 개인 성적 진입 |
| `players.html?player=<playerId>` | 특정 선수의 개인 프로필 |
| `players.html?player=haeram&demo=1` | 가상 데이터가 적용된 해람 프로필 |
| `import.html` | 경기 JSON 입력, 프롬프트 복사, 검증·매칭·등록 |
| `admin.html` | 소유자의 관리자 권한 관리 |

개인 페이지의 `date` 쿼리는 경기일을 제한합니다. 그 안에서 라인·챔피언 필터와 탐색/경기 목록/상세 통계 보기를 조작합니다. 이 세부 탐색 선택은 현재 화면 상태이며, 별도 저장 통계가 아닙니다.
